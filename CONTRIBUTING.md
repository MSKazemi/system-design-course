# Contributing to System Design

Suggestions about learning clarity, source accuracy, diagrams and reproducibility are welcome after an approved public repository exists. Course owners should review proposed changes for technical accuracy, access rights, safety, and confidentiality.

Use synthetic examples only. Do not submit credentials, personal data, proprietary source material, confidential infrastructure, or unlicensed figures. Distinguish documented behavior from runtime-tested claims. Cite official versioned documentation and primary research when appropriate.

A public repository or issue tracker has not been established by the factory's local scaffolding step.
